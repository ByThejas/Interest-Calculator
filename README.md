# ☕ Simple & Compound Interest Calculator

> Day 2 of learning Java.
> Built this instead of just watching another tutorial.

## ✨ About

A simple menu-driven Java application that calculates:

- 📈 Simple Interest
- 📊 Compound Interest

The user can choose which calculation they want, enter the required values, and get the final amount along with the interest earned.

This project was less about the math and more about understanding Java fundamentals.

---


Probably spent more time debugging than writing code... and honestly that's where the learning happened.

---

## 🚀 Features

- Menu-driven interface
- Separate methods for:
  - Simple Interest
  - Compound Interest
- Calculates:
  - Interest Earned
  - Final Amount
- Clean formatted output
